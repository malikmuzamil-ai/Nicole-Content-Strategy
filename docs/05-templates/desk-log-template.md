# Template · Desk Log

Filled during and after every window. The log is what makes the account auditable, and the
refusals in it are half the work.

---

## Single comment

```
COMMENT   the text, line breaks as they should appear
TYPE      one of the seven
LANE      green, amber or red
TRACE     where the material came from, one line
```

Four things and nothing else. No preamble, no explanation of the craft unless it is asked for.

---

## Window run

```
WINDOW · DD MONTH · POST ID 00 · T = 09:00


T-30 to T-5       target list pass
  09:00-05  name / tier / type / lane        placed
  ...
  Refusals:
    name / tier / reason in four words

T-5 to T          nothing goes out

T                 own first comment, source link              placed / none

T to T+30         replies first, then outward
  Replies:        00 of 00 substantive comments answered
  Outward:        name / tier / type / lane

T+2h              sweep one, 00 replies
T+24h             sweep two, 00 replies, thread closed


TOTALS            placed 00 · refused 00 · replies 00 · held amber 00
```

**A run with four comments and eleven refusals is reported as a full run, not a thin one.**

---

## Weekly table

```
POST                POSTER          TIER    TYPE    LANE    TRACE
...


REFUSALS
POST                POSTER          TIER    WHY
...
```

The refusal reasons are the most useful thing in this document over time. They build the real
target list faster than the placements do.

---

## Refusal reasons, the standing set

Use these words so the log is countable.

| Reason | Meaning |
|---|---|
| `nothing to add` | The honest comment would be nothing. The most common and the most valuable |
| `would be correcting` | A public correction makes her the hero of somebody else's post |
| `generic category` | Files her with the people she has spent years getting away from |
| `competitor` | Not done, in either direction |
| `stance` | Political, national, religious, or a live controversy |
| `named private life` | The fence rule makes it impossible |
| `outside territory` | Chasing reach. Reach is not the mechanism |
| `red, held` | Went to her directly instead |

---

## The daily ceiling

| | |
|---|---|
| Posting day | 8 to 12 outward, plus every reply |
| Non-posting day | 2 to 4, or none |
| **Hard ceiling** | **15.** Past that it is volume, and volume is not the strategy |

Eight comments that could only have come from her beats fifteen that could have come from anyone.
