# Nicole Brandes · Content Operating System

Everything needed to run the LinkedIn content engine, the funnel underneath it, and the weekly
workflow that keeps both moving. One folder, one source of truth, nothing kept in somebody's head.

**Status:** v1.0, built 21 September 2026
**Owner:** Purely Personal
**Confidentiality:** Private. Prepared for Nicole Brandes. Not for distribution.

---

## What this is

The strategy was settled in `source/original-strategy-deck.html`. That deck answers *what* we are
doing. This folder answers *how it gets done, every week, by whoever is at the desk.*

Twenty five documents across five layers, plus six templates. Each one is written to be picked up cold by somebody who
has never seen the account and still produce work that sounds like her.

```
Foundation   ->  who she is, who it is for, how she sounds, what she sells
Strategy     ->  what gets published, in what shape, on what day
Funnel       ->  how a reader becomes an application becomes a client
Workflow     ->  who does what, in what order, with which approval
Templates    ->  the forms the work actually gets done on
```

## The three rules that govern this whole folder

1. **Nothing publishes without her yes.** Draft, log, Nicole, publish. No standing approval has
   been granted yet.
2. **No unconfirmed credential, no identifiable client detail.** Ever, including on a day a post
   would obviously be stronger with one. See
   [07 · Claims and Confidentiality Charter](docs/01-foundation/07-claims-and-confidentiality-charter.md).
3. **The only number that matters is Assess applications.** Reach, likes and follower count are
   diagnostics, not targets. See [20 · Measurement and Reporting](docs/04-workflows/20-measurement-and-reporting.md).
